Difference between paging and segmentation?

KS
Kabir S.
→ addressed to Sherly Roy Filed 3 days ago

I keep mixing up paging and segmentation in OS. Both seem to split memory into chunks, so I don't understand why an operating system would need both, or when one is actually better than the other. I've attached a diagram from my notes below — I think I've drawn it wrong somewhere.

From Sherly Roy

Good question — the short version is that they solve different problems. Paging splits memory into fixed-size frames purely for the OS's bookkeeping, so the programmer never sees it. Segmentation splits a program into logical units — code, stack, data — that actually mean something to the programmer, but those units can vary in size, which makes fitting them into physical memory harder.

Most modern systems actually combine both: segments that are themselves paged. Try redrawing your diagram with two layers — logical segments on top, fixed pages underneath — and it should click.
